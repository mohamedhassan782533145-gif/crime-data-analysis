# Crime Data Analysis

## Description

This project analyzes crime data using Python, Pandas, and NumPy. The project focuses on cleaning, processing, and analyzing crime datasets to discover patterns, trends, and useful insights.

## Tools Used

* Python
* Pandas
* NumPy
* Excel

## Features

* Read and process crime data from Excel files
* Clean and prepare the dataset for analysis
* Analyze crime patterns and trends
* Calculate statistical insights from the data
* Extract useful information from crime records

## How to Run

### Install required libraries:

```bash
pip install -r requirements.txt
```

### Run the project:

```bash
python p2.py
```
